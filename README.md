# Space Flight — 2D-симулятор ракет и Солнечной системы

Собери ракету из деталей, запусти, выйди на орбиту, сделай манёвр, долети до Луны, Марса и дальше, сядь и вернись.

## Запуск
В папке проекта: `python3 -m http.server 8000` (или `npm start`), затем http://localhost:8000
(ES-модули не работают при открытии index.html двойным кликом).

**Версия для ПК (Electron):** `npm install` (один раз), затем `npm run desktop`; `npm run dist` собирает переносимый .exe для Windows.
Оболочка не запускалась в среде разработки (нет загрузки Electron); её сервер статики покрыт тестом `tests/server.mjs`.

## Проверка — `npm test`
- `tests/flight.mjs` — физика, мир, шаблоны, свободные чертежи, топливо по ступеням, орбиты вокруг подвижных тел, перелёты к Луне/Марсу/Солнцу, посадки, парашют.
- `tests/server.mjs` — сервер для ПК и закрытие лишних файлов.
- `tests/smoke.mjs` — весь интерфейс в поддельном браузере: меню, ангар (перетаскивание, прикрепление, отказы, удаление, отмена, чертежи), пауза, полёт, карта, посадки, крушение.

## Ангар (свободная сборка)
Деталь берут из каталога **мышью**, ведут к ракете и отпускают: она цепляется к ближайшему подходящему узлу (подсвечены кружками, зелёный — выбранный). Клик по детали каталога добавляет её автоматически.
Ограничения: деталь обязана быть присоединена к ракете; детали не пересекаются; капсула одна; у деталей свои узлы (двигатель — только сверху, капсула — только снизу, опоры, парашюты, двигатели ориентации, бустеры — к боку баков и капсулы); без капсулы, двигателя, топлива в нижней ступени и при тяге/весе < 1 запуск запрещён.
Тянуть деталь — переставить её вместе с присоединённым; тянуть капсулу — сдвинуть всю ракету; Del / правая кнопка — удалить с присоединённым; Ctrl+Z — отмена; колесо — масштаб; тянуть фон — сдвиг; F — по центру. «Симметрия» ставит радиальные детали парой. Чертежи сохраняются под именем (вкладка «Чертежи»), там же шаблоны.

## Детали (30 штук)
Капсула и зонд · баки: узкий, малый, средний, большой, огромный, широкий · двигатели: «Стриж», «Шмель», «Бизон», «Мамонт», вакуумный «Эфир», ионный «Луч» · разделитель, переходник 3 → 1,8 м, обтекатель (снижает сопротивление) · двигатели ориентации, опоры, парашют, солнечные панели (U — раскрыть) · бустеры большой и малый.
Радиально (к боку баков, капсулы и переходника) можно крепить баки, двигатели, бустеры, опоры, панели и двигатели ориентации. Шаблоны: «Прыжок», «Орбитальная», «С ускорителями», «Спутник», «Лунная».

## Физика
- Интегрирование идёт в системе доминирующего тела (устойчивые орбиты вокруг движущихся тел), но на аппарат действует **гравитация всех близких тел**: центральное тело, Солнце, родитель и спутники или планеты в виде приливных членов. Луна притягивает вне своей сферы влияния, Юпитер возмущает полёты по Солнечной системе. Проверено сравнением с прямым инерциальным интегрированием.
- Шаг интегратора адаптивный: по времени пролёта и динамическому времени тела √(d³/μ).
- Голубая линия в полёте — путь вперёд без тяги (с затуханием, стрелками направления и меткой удара); на карте — траектория с манёвр-узлами.

## Графика и производительность
Ракета всегда рисуется в истинном размере; когда она слишком мала для рисунка — белый треугольник. При малом масштабе детали рисуются упрощённо. Звёзды — один раз в отдельный холст, частицы — пачками, прогноз на карте кэшируется и для замкнутой орбиты считает один оборот, положения всех тел — за один проход. В среде без видеокарты все сцены держат ~60 кадров/с.

## Ступени и топливо
Ступень — часть ракеты между разделителями. Двигатели ступени тратят **только топливо баков своей ступени**; пока она не отделена, топливо верхних ступеней не трогается. Когда топливо ступени кончилось, двигатели глохнут; после отделения (Пробел) включается следующая ступень. Бустеры сжигают своё топливо и сбрасываются первыми.

## Структура
| Путь | Назначение |
|---|---|
| `src/world.js` | Солнце, 8 планет, 5 спутников; сферы влияния, рельеф, атмосферы |
| `src/physics.js` | RK4 в системе доминирующего тела (сопряжённые конусы), прогноз траектории, апсиды |
| `src/parts.js` | каталог деталей; модель чертежа (детали + связи), граф ступеней, проверки, Δv по ступеням |
| `src/rocket.js` | ракета: расход топлива по ступеням, Isp от давления, поворот с учётом массы, парашют, опоры, посадка |
| `src/vab.js` | ангар: перетаскивание, прикрепление к узлам, ограничения, чертежи, вид-чертёж |
| `src/ui.js` | главное меню, меню паузы, справка |
| `src/draw.js`, `src/render.js` | графика деталей; сцена полёта (небо, планеты с текстурами, рельеф), карта, HUD |
| `src/particles.js`, `src/sound.js` | огонь, дым, пыль, газ; синтезированный звук |
| `src/missions.js`, `src/input.js`, `src/main.js` | достижения, управление, цикл игры |
| `assets/planets/*.png` | текстуры 14 тел (`python3 tools/make_assets.py`, нужны numpy и Pillow) |

## Управление (полёт)
Z/X — газ · Shift/Ctrl — плавно · A/D — поворот · Пробел — ступень · P — парашют · U — солнечные панели · T — SAS · `,` `.` — время · M — карта · колесо — масштаб · **Esc — меню паузы** (продолжить, вернуться к сборке, главное меню) · R — заново · B — ангар · N — звук · H — справка.
